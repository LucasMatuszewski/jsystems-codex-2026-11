# Version 1 - Built-in subagents only

Use the host's native child-agent mechanism for workers and independent review. Do not substitute shell-launched Codex, Claude, OpenCode or `agy` workers in this version.

## Plan the mechanism

- Inspect the active harness's actual tools, feature settings and any existing named roles. Availability in another product/session does not prove availability here. Record concurrency and model-selection constraints, inheritance and effective file/tool access.
- Codex example: capable Sol orchestrator, Luna for bounded implementation/tests or fact-only research, fresh capable reviewer. These are capability examples; choose an identifier actually exposed by the host.
- Claude Code example: capable orchestrator/reviewer with a Haiku-class bounded worker if the selected version/account and task support it. Verify native subagent/model controls in installed help/current official docs. Do not translate Codex spawn parameters into Claude syntax.
- In Antigravity or another host, inspect native delegation support first. If unavailable, leave this mode sequential with the capable orchestrator or obtain approval to use version 2. A terminal button or `--agent` session selector is not evidence of child-agent dispatch.
- Prefer ad hoc task briefs. Existing reusable roles need permission/model inspection; new definitions are justified by recurring restrictions/expertise only.

## Execute only after authorization

The orchestrator refreshes the checkout, writes the durable brief and uses the verified native mechanism with exact ownership. Research workers report sources/limitations without choosing architecture. Implementation workers stop on contradictions or out-of-scope files.

Native children may inherit context but still need a self-contained brief with current predecessor outputs. Context inheritance and model inheritance are separate controls. Do not claim a cheaper model was selected when the harness ignored or cannot express that selection.

Parallel work needs independent inputs and disjoint files. Wait for accepted prerequisites before dispatch; serialize shared contracts and integration. If a native worker is unavailable or fails beyond the agreed repair boundary, the capable orchestrator can execute the same row sequentially with the same evidence. Do not quietly launch an external CLI worker.

The orchestrator reviews diffs/reproduces checks before commits. A fresh non-author capable agent reviews the current candidate after authors stop editing. If no independent native reviewer is available, name the gap and use an independent human or approved later review; self-review is not independent acceptance.
